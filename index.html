GOLDFPS

Beta build for testers, Windows 64-bit
Download for Windows Latest beta
Install
  1. Download goldfps.exe (about 140 MB) and run it. No installer.
  2. Windows SmartScreen may warn because the game isn't signed: click More info then Run anyway.
  3. Make a profile, then set a password in Profile so you can log in again later. Passwords can't be recovered.
